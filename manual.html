基本システム（共通環境・ログ仕様）

トップ画面に常駐するインフォメーションボード、および自動配信されるシステムログの構造説明です。

インターフェース要素 機能と詳細仕様
MANUAL リンク お知らせ枠の左上枠外にマウントされています。本説明書を瞬時に展開可能です。
UPDATE LOG リンク お知らせ枠の右上枠外にマウント。過去3日以内に新規アップデートログが配信されている場合、左隣にシアンネオンの青い通知ドット（〇）が自動点灯・明滅します。
SYSTEM NOTIFICATION システム全体への伝達事項がリアルタイム同期されます。最重要情報は最上部に 📌 PINNED バッジが常時点灯して最前面に固定されます。
コメント・バグ報告フォーム 運営宛てにメッセージを送信できます。テキスト入力エリアは視認性を極限まで高めた極美サイバーイエロー（#ffff00）仕様です。

■ システム拡張履歴（UPDATE LOG）の仕様

  • 視認性特化レイアウト：文章の本文のみを完全左寄せ（text-align: left;）に指定。箇条書き（・）などを多用しても先頭ラインがカチッと美しく整列し、 scannable な視認性を実現します。
  • NEWインジケーター：新しいログが追加された瞬間から、ジャスト3日間（72時間）限定で、バージョンの右隣にサイバーNEWバッジが自動点灯・明滅します。期限経過後は手動の手間なく自動消灯します。

■ メンテナンスロック（WARNING）時の挙動

システム一斉ロックダウンが有効化された場合、画面は強制的に遮断専用ページへと切り替わります。完全独立ファイルの採用により、本番データのチラ見えは物理的に一切発生しません。

◈ メンテナンス画面の構成（上からの黄金整列）

【お知らせ掲示板】 ➔ 【状況確認・メッセージ送信フォーム】 ➔ 【WARNING 警告ボックス】

  • ロックダウン中であっても、最上部のお知らせエリアから状況や終了予定をリアルタイムに確認可能です。
  • 不具合報告やメッセージは、専用フォームから随時送信できます。
  • 管理側でメンテナンスが解除された瞬間、ページを一切操作していなくても、全自動で元のルーム選択画面へ引き戻される復旧感知センサーが組み込まれています。

運用システム（ルーム選択・各モード操作）

各トレーニングルームへのエントリー手順、および入室後の役割に応じた端末操作の解説です。

■ ルーム選択と入室プロトコル

  1. ルームの状況確認：ROOM 01〜10 の中から空いている部屋（グリーンの ● EMPTY 表示）を選択してクリックします。すでに使用中の部屋は赤く脈動し ● IN USE と表示されます。
  2. アクセスモードの選択：ルームをクリックすると専用ポップアップウィンドウが展開されます。ご自身の役割に応じて以下の3つのモードからいずれかを選択して起動してください。

■ 各モードの操作仕様

  • ◈ JUDGE MODE 審判・管理者画面

    該当ルームのダミー人形のステータス変更、およびタイムライン管理を行う最高同期コントロール権限を持ちます。

    1. ライフ（HP）の同期制御：スライダーまたは増減コマンドを使用し、ダミー人形の残りライフをリアルタイムに変更します。操作した数値は、選手・観客全員の端末に100%即時同期されます。
    2. タイマーマネジメント：中央タイマーの【スタート / ストップ / リセット】を制御します。カウントダウンの挙動もリアルタイムに全同期されます。
    3. ルームの初期化・退出：終了時は、必ずルームのオンラインシグナルをリセットしてから退出してください（リセットすることで、トップページの表示が再び EMPTY に戻ります）。
  • ◈ PLAYER MODE 選手画面

    トレーニングや競技に直結する自身のステータス、および時間経過を高精度で追跡するモニタリングノードです。

    1. リアルタイムHPゲージ監視：審判が操作したライフの変動データが、なめらかなバーエフェクトを伴って画面に即時描写されます。自身の残存率をミリ秒単位で確認可能です。
    2. 同期カウントダウン確認：中央タイマーと完全同期した残り時間が目の前に描画されます。審判側でタイマーが停止した際は、選手側のカウントもその瞬間にジャストで停止します。
  • ◈ SPECTATOR MODE 観客画面

    トレーニングエリアの状況を俯瞰し、データの変更を一切行わずに高精度監視する純粋なライブモニターノードです。

    1. 全ステータスのパッシブ同期：審判がコントロールするライフ値、および駆動しているタイマーの数値を1ミリの遅延もなく受信し、大型ディスプレイや個人端末へ美しくシネマティックに描写し続けます。
